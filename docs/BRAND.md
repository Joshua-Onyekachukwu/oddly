# ODDLY — Brand Identity

## Brand Name

**ODDLY**

## Tagline

*"Oddly accurate."*

---

## Why This Name

- **One word.** Weird enough to make someone stop scrolling. Clean enough to put on a T-shirt.
- **"Oddly" as in "oddly accurate"** — the model is surprisingly, unexpectedly precise.
- **Short. Memorable.** Works as a brand, a hashtag, a username.
- **Nigerian kid in Lagos sees "ODDLY" on a flyer and goes "what is this?" and downloads the app.** That's the whole marketing strategy in one word.

---

## Logo Concept

A **fox** (clever, sharp, hunts with precision) or a simple **wordmark** with the O stylized as a probability curve or odds decimal.

### Logo Variations

| Version | Use Case |
|---------|----------|
| Full logo (fox + wordmark) | Primary branding, landing page |
| Wordmark only | App header, favicon |
| Icon only (fox) | App icon, social media |
| Monochrome | Documents, stamps |

---

## Brand Voice

### Tone

**Honest. Transparent. Direct.**

- Never says "sure bet"
- Always says "the model estimates"
- Shows losses alongside wins
- Built on trust through radical transparency

### Language Rules

| Do | Don't |
|----|-------|
| "The model estimates 84% probability" | "This is a guaranteed win" |
| "Edge: +6% (moderate value)" | "SMART BET 💰🔥" |
| "Risk: High. 38% chance of hitting." | "Low risk, high reward!" |
| "This accumulator has 0.2% chance" | "Turn ₦1,000 into ₦1M!" |
| "The model was wrong here" | *Delete losing prediction* |

### Example Copy

**Good:**
> "Over 1.5 Goals — 84% probability. Edge: +6%. The model estimates this outcome is undervalued by the market. Data quality: 91/100."

**Bad:**
> "🔥 SURE GAME 🔒 OVER 1.5 GOALS 💰💰💰 TRUST THE PROCESS"

## Visual Identity

### Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| Primary (Deep Navy) | `#0F172A` | Backgrounds, headers |
| Accent (Electric Orange) | `#F97316` | CTAs, highlights, fox |
| Success (Green) | `#22C55E` | Wins, positive values |
| Warning (Amber) | `#F59E0B` | Caution, medium risk |
| Danger (Red) | `#EF4444` | Losses, AVOID flags |
| Neutral (Gray) | `#64748B` | Body text, borders |
| Background (Off-white) | `#F8FAFC` | Page backgrounds |

### Typography

| Element | Font | Weight |
|---------|------|--------|
| Headings | Inter | Bold (700) |
| Body | Inter | Regular (400) |
| Data/Numbers | JetBrains Mono | Medium (500) |
| Captions | Inter | Light (300) |

### Design Principles

1. **Data-first.** Numbers and probabilities are the hero.
2. **Honest density.** Show more information, not less. Users want data.
3. **Risk-aware UI.** Red for danger, green for value, amber for caution.
4. **Mobile-first.** Nigerian users are primarily on mobile.
5. **Dark mode ready.** Data-heavy apps work better in dark mode.

## Brand Don'ts

- ❌ Never use "sure bet," "guaranteed," "lock," "banker"
- ❌ Never use 🔒🔒🔒 or 💰💰💰 emojis
- ❌ Never hide losing predictions
- ❌ Never show only wins in marketing
- ❌ Never promise returns
- ❌ Never use gambling imagery (dice, cards, slot machines)
- ❌ Never target vulnerable users
- ❌ Never use pressure tactics ("Limited time!" "Don't miss out!")

---

## Brand Dos

- ✅ Show model accuracy transparently
- ✅ Show losses alongside wins
- ✅ Use probability language ("84% chance")
- ✅ Use edge language ("+6% edge")
- ✅ Show data quality scores
- ✅ Educate users on risk
- ✅ Use the fox as a mascot (clever, precise)
- ✅ Be weird. Be different. Be ODDLY.
